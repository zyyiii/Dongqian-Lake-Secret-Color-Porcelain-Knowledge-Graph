# 🫖 东钱湖秘色瓷 · 湖泥与焰火的千年秘语

> 基于考古资料与学术研究的东钱湖秘色瓷交互式知识图谱，探索千年青瓷的文化脉络。

## 📖 项目简介

本项目以**东钱湖秘色瓷**为主题，构建了一个集知识图谱、时光轴、工艺展示、古今对比、文创廊、传承人星谱和知识库于一体的交互式单页网站。

网站涵盖了从东汉晚期窑场初创到当代非遗传承的完整脉络，所有内容基于真实考古资料、学术研究与新闻报道：

- 🏛️ 郭家峙、郭童岙、上水岙、老虎岩四大窑址
- 🏺 镂雕凤纹香薰盖、花口莲瓣纹尊、雀绕牡丹纹钵等出土精品
- 🔬 瓷质匣钵封釉工艺、湖泥养炼等核心技术
- 👨‍🎨 闻长庆、闻果立、赵路路三代传承人
- 🎨 莲荷纹、对蝶纹、鹦鹉纹、鹰纹等经典纹样
- 🛍️ 东钱壶、圆融杯、肇新饰品等现代文创

## ✨ 八大模块

| 模块 | 说明 |
|------|------|
| **秘色宇宙** | 首页总览，粒子动画背景，快速导航卡片 |
| **知识图谱** | D3.js 力导向图，拖拽探索节点关系，四条路径切换 |
| **时光轴** | 水平滚动时间线，从东汉至2026年十二个关键节点 |
| **湖泥独韵** | 八大工序步骤（采泥→淘洗→拉坯→刻花→施釉→装匣→烧制→开片），可展开详情 |
| **古今对话** | 古代残片 vs 现代新作的拖拽对比，透明度叠加对比 |
| **文创廊** | 陶瓷/配饰/礼盒三类产品卡片，弹窗详情 + 设计解码 |
| **传承人星谱** | 人物卡片 + SVG 关系图谱，展示三代传承脉络 |
| **知识库** | 可搜索筛选的知识条目库，24条考古/人物/器物/工艺/纹样/文创资料 |

## 🎨 设计理念

### 色彩系统

取色自秘色瓷「青绿中微泛黄」的釉色特征：

- **主色调**：青绿色系（`celadon`），从 `#f0f7f4` 到 `#0d271b`
- **辅助色**：金色（`gold`）、湖泥色（`lake-clay`）、羊皮纸色（`parchment`）
- **节点色**：8种颜色区分知识图谱节点类型

### 排版

- **标题字体**：Noto Serif SC（思源宋体）
- **正文字体**：Noto Sans SC（思源黑体）
- **字号体系**：基于根元素 `16px` 的 rem 系统
